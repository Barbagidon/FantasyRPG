# 🛡️ FantasyRPG — Главный Портал Wiki & Документация

Добро пожаловать в базу знаний и техническую документацию проекта **FantasyRPG** — тактической пошаговой PvE RPG с линейной сюжетной кампанией и кооперативом до 3 игроков (*боевая система вдохновлена DOS2/BG3/Pillars, но объём осознанно урезан для соло-разработки — см. `roadmap.md`*).

Единственный портал вики — этот файл. `project_wiki.md` в корне репозитория был его побайтовым дублем и теперь просто указывает сюда.

## 📚 Разделы Модульной Документации

## 🎯 Статус проекта

Актуальный статус и критерии закрытия каждого этапа — в `roadmap.md`. Здесь — только напоминание правила: **пункт считается сделанным только если он подтверждён автотестом (для `Core`) или запускаемым билдом (для всего остального)**, а не потому что файл создан. Предыдущая версия этой вики отмечала «Сессия 2 — 100% завершено», хотя расход AP не был подключён к выполнению команд ни в одном месте кода — это и есть пример того, чего это правило должно не допускать впредь.
