# Architecture Decision Records

Каждый файл — решение по одному конкретному техническому или геймдизайнерскому вопросу,
зафиксированное с альтернативами и причинами отказа от них. Неизменяемы после принятия:
изменившееся решение — это новый ADR со ссылкой «Superseded by ADR-000N», не правка старого.

Статусы: `Proposed` (обсуждается) / `Accepted` (решено, реализация не обязательно начата —
статус кода живёт в `docs/roadmap.md`, не здесь) / `Superseded`.

| № | Решение | Статус |
|---|---|---|
| [0001](./0001-pathfinding-bounded-dijkstra.md) | Bounded Dijkstra + compact open-set для перемещения по сетке | Accepted |
| [0002](./0002-action-points-and-movement-economy.md) | Единая AP-экономика и стоимость перемещения (`Movement`) | Accepted |
| [0003](./0003-movement-legality-occupancy-and-diagonal-corners.md) | Легальность перемещения, занятость клеток и диагональные углы | Accepted |

## ⚠️ Контракт `Pathfinder` эволюционирует между ADR — читай последний

ADR неизменяемы, поэтому контракт `Pathfinder` **дописывается** последующими ADR, а не
правится в исходном. Если читать только ADR-0001, сигнатура и предикаты будут устаревшими:

| Что | Где актуальная версия |
|---|---|
| Сигнатура `FindReachable` | **ADR-0003**, раздел «Поправки к контракту ADR-0001» — `FindReachable(start, actionPointBudget, movement, mover, movementContext)` |
| `CanTraverse` / `CanStopAt` | **ADR-0003** — `CanTraverse(from, to, mover)` (получает mover, чтобы различать `Self`/`Ally`/`Enemy`), `CanStopAt(cell)` без mover и без знания о `start` |
| Стоимость ребра | **ADR-0002** — `ceil(baseStepCost * 100 / Movement)`, база `10/14` из ADR-0001 |
| Публичная семантика результата | **ADR-0003** — `TryGetCost` / `CopyReachableTo` / `CopyPathTo` с разными областями определения |
| Алгоритм и структуры | ADR-0001 (не менялся) |

Правило для будущих ADR: любой ADR, меняющий входы или результат `Pathfinder`, обязан
содержать раздел с **полным** актуальным контрактом, а не только локальную поправку.
