# Architecture Decision Records

Каждый файл — решение по одному конкретному техническому или геймдизайнерскому вопросу,
зафиксированное с альтернативами и причинами отказа от них. Неизменяемы после принятия:
изменившееся решение — это новый ADR со ссылкой «Superseded by ADR-000N», не правка старого.

Статусы: `Proposed` (обсуждается) / `Accepted` (решено, реализация не обязательно начата —
статус кода живёт в `docs/roadmap.md`, не здесь) / `Superseded`.

| № | Решение | Статус |
|---|---|---|
| [0001](./0001-pathfinding-bounded-dijkstra.md) | Bounded Dijkstra + compact open-set для перемещения по сетке | Accepted |
| [0002](./0002-action-points-and-movement-economy.md) | Единая AP-экономика и стоимость перемещения (`Movement`) | Accepted |
